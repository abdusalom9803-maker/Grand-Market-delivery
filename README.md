# GRAND MARKET — ишлайдиган старт версия

Бу код серверда ишга туширилганда маҳсулотларни кўрсатади, саватча тузади, буюртмаларни SQLite базасига сақлайди ва Telegram'да эга ҳамда администраторга хабар юбора олади.

## Ишга тушириш
1. Python 3.10+ ўрнатилган серверда `pip install -r requirements.txt`
2. `BOT_TOKEN`, `OWNER_CHAT_ID`, `ADMIN_CHAT_ID`, `ADMIN_KEY` муҳит ўзгарувчиларини белгиланг. Токенни чатга ёки кодга ёзманг.
3. `python app.py` (локал тест учун); оммавий HTTPS серверда production WSGI серверидан фойдаланинг.
4. Telegram хабарлари ишлаши учун эга ва администратор аввал ботга /start юбориши керак. Chat ID'ларни ишончли усулда аниқланг.
5. Mini App'ни HTTPS доменга жойлаштириб, BotFather орқали URL'ни боғланг.

## API
GET /api/products — каталог
POST /api/orders — буюртма
GET /api/admin/orders — X-Admin-Key сарлавҳаси билан буюртмалар
PATCH /api/admin/orders/<id> — X-Admin-Key ва {"status":"confirmed"} каби JSON

## Ҳозирча уланмаган
- 1С импорт/синхронлаш; каталог 6 та намунавий маҳсулотдан иборат.
- Click/Payme ҳақиқий тўловлари. Ҳозир буюртма фақат етказганда тўлов учун.
- Telegram WebApp initData серверда текшириш ва Telegram login.
- Курьер панели, масофани харита орқали ҳисоблаш, иш вақтида автоматик чеклов, stock reservation.

## Хавфсизлик
ADMIN_KEY ни узун тасодифий сир қилинг, HTTPS ишлатинг, шахсий маълумотлар ва база учун киришни чекланг. Ишга туширишдан олдин rate limit, журналлаш, захира нусха ва ишлаб чиқариш хавфсизлик текшируви керак.
