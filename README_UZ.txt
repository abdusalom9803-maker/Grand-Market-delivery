GRAND MARKET DELIVERY — 1CСИЗ АДМИН-ПАНЕЛЬ + EXCEL ИМПОРТ
===================================================

Бу алоҳида excel-admin branch учун тайёрланган тест версияси.
Ҳозирги main / 1c-integration branch'ларини ўзгартирманг.

ИЧИДАГИ ФАЙЛЛАР
- app.py             Flask сервери, 1Cсиз каталог, буюртмалар, админ API.
- index.html         Мижозлар учун саҳифа, қидирув, ТОП-200, саватча, буюртма.
- admin.html         /admin — кириш, маҳсулотлар, нарх, қолдиқ, расм URL, Excel, буюртмалар.
- xlsx_reader.py     Excel (.xlsx) файлни ўқиш; 1C интеграцияси шарт эмас.
- catalog_seed.json  6297 та омборда мавжуд товарнинг код/ном/сотув нархи/қолдиғи;
                     ТОП-200 маҳсулот белгиси. Таннарх ва харид нархлари ЙЎҚ.
- requirements.txt   Render'га керакли Python пакетлар.

1) GITHUB'ДА ФАҚАТ excel-admin BRANCH'ГА ЮКЛАНГ
   а) ZIP'ни телефон ёки компьютерда очинг/архивдан чиқаринг.
   б) Репозиторий → excel-admin branch.
   в) app.py, index.html, requirements.txt ни ШУ branch'да алмаштиринг.
   г) admin.html, xlsx_reader.py, catalog_seed.json ни қўшинг.
   д) README_UZ.txt ва .gitignore ихтиёрий.
   е) ZIP архивининг ўзини GitHub'га юклаш етарли ЭМАС: файлларни очиб қўйиш шарт.
   Старый main branch қолади ва ишлайди (агар Render main'га боғланган бўлса).

2) RENDER'ДА АЛОҲИДА ТЕСТ ХИЗМАТИ
   GitHub branch: excel-admin
   Build command: pip install -r requirements.txt
   Start command: gunicorn --workers 1 --bind 0.0.0.0:$PORT app:app
   Environment variables:
     ADMIN_KEY = ўзингиз билган кучли махфий парол (ҳеч кимга кўрсатманг)
     SECRET_KEY = узун тасодифий сир (Render'да янги қўшинг)
     DATABASE_URL = Render PostgreSQL'нинг connection string манзили
     BOT_TOKEN = Telegram бот токени (илгари бўлса, қайта фойдаланинг)
     OWNER_CHAT_ID = Telegram Chat ID
     ADMIN_CHAT_ID = иккинчи Chat ID (ихтиёрий)
   Изоҳ: DATABASE_URL бўлмаса, SQLite ишлайди, лекин Render'нинг
   одатдаги вақтинча дискида маълумотлар қайта deploy'да йўқолиши мумкин.
   Реал буюртмалар ва доимий қолдиқлар учун PostgreSQL зарур.

3) АДМИНГА КИРИШ
   https://<test-service>.onrender.com/admin
   ADMIN_KEY ни киритинг. Паролни кодга ёзманг ёки GitHub'га жойламанг.
   Илк ишга тушишда, база бўш бўлса, 6297 товар автоматик юкланади.
   Каталог ва ТОП-200 мижозлар саҳифасида чиқади.

4) EXCEL ИМПОРТ
   /admin → Excel импорт → GRAND_MARKET_SAYT_IMPORT_TOP200.xlsx танланг.
   Саҳифа: Sayt_katalogi (устунлар: code, name, price, stock, image_url,
   category, featured, active).
   Бир хил code бўлган маҳсулот UPDATE қилинади — дубликат қўшилмайди.
   Биринчи/кейинги экспортларда нарх ва қолдиқлар янгиланади.
   Расм URL'лари Excel'да бўш бўлса, админда киритилгани сақланади.
   «Файлда йўқ маҳсулотларни яшириш» белгисини фақат файл тўлиқ
   каталог эканига ишончингиз бўлса танланг.
   .xlsx файлни ўзи юкланади, таннарх/фойда жадвали серверга кўчирилмайди.

5) МАҲСУЛОТЛАРНИ БОШҚАРИШ
   /admin → Маҳсулотлар. Код ёки ном бўйича топинг → Таҳрир.
   Нарх, қолдиқ, категория, ТОП белгиси ва https:// билан бошланадиган
   РАСМ ҲАВОЛАСИ (image_url) ни киритиш мумкин.
   Расмнинг ўзини юклаш ҳозирча йўқ; расмни Google Drive private link'и
   эмас, оммавий кўринадиган тўғридан-тўғри HTTPS расм URL'и қилинг.
   «Маҳсулотни яшириш» базадан ўчирмайди, фақат савдодан яширади.

6) БУЮРТМАЛАР
   Мижоз буйруқ юборганда сервер маҳсулот нархини ва қолдиғини ўзи
   қайта текширади. Қабул қилинган миқдор қолдиқдан айирилади.
   Бекор қилинган буюртмада қолдиқ қайта қўшилади.
   Telegram'га хабар BOT_TOKEN/OWNER_CHAT_ID ўрнатилган бўлса юборилади.
   Тўлов — етказилганда. Онлайн Click/Payme уланмаган.

МУҲИМ ОГОҲЛАНТИРИШЛАР
- Бу версия тест учун. Мижозлар билан ишлашдан олдин масъул киши
  синов буюртмалар, Telegram хабарлари, нархлар, омбор қолдиқлари,
  оддий товарлар ва килограмм товарларни текшириши керак.
- Ҳар бир импортдан аввал база backup нусхасини олинг.
- 1C Excel экспорти билан база орасида реал вақт синхронизацияси ЙЎҚ.
- 1Cдан олинган қолдиқларни сайтдаги буюртмалар ҳам камайтиради;
  кейинги Excel юклашда қолдиқлар тўлиқ қайта ёзилади. Бир хил
  даврдаги савдони икки марта ҳисобламаслик учун тартиб керак.
- SECRET_KEY ва ADMIN_KEY кучли, махфий бўлсин. HTTPS талаб қилинади.
- Хавфсизлик ва юридик текширувисиз дарҳол умумий реклама қилманг;
  Render ишончли база, захира ва кузатувни созланг.

ЛОКАЛ ТЕСТ (дастурчи учун)
  python -m venv .venv
  pip install -r requirements.txt
  ADMIN_KEY ва SECRET_KEY ўзгарувчиларини тайинланг
  COOKIE_SECURE=0 (фақат localhost HTTPда!)
  python app.py
  http://localhost:5000/
  http://localhost:5000/admin

АВВАЛГИ ИЛОВА БИЛАН МОСЛИК
- GET /api/products              — аввалгидай маҳсулотлар массиви;
                                   6297 маҳсулот учун секин бўлиши мумкин.
- GET /api/products?page=1&limit=24 — янги саҳифаланган API.
- POST /api/orders               — аввалги JSON буюртма формати.
- GET /api/admin/orders          — эски X-Admin-Key сарлавҳаси ҳам ишлайди.
- PATCH /api/admin/orders/<id>   — буюртма ҳолатини ўзгартириш.
